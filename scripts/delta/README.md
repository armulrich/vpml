# Delta launchers

See the [Delta usage guide](../../docs/delta.rst) for environment setup,
preparation, validation, submission, monitoring and continuation.

`gaussian_amplitudes_v1.params.sh` selects scheduler resources and the adjacent
JSON supplies the scientific parameters. The launcher requires an explicit
action; only `submit` requests a real allocation. Array definitions and
numerical checks are documented in the [dataset guide](../../docs/datasets.rst).
